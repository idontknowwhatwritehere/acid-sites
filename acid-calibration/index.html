При R² выше 0,999 вкладки окрашиваются в зелёный: чем выше R² среди кислот, тем насыщеннее цвет. При R² до 0,999 включительно цвет зависит от диагностики: жёлтый — проверить, оранжевый — есть сильно влияющие точки, красный — есть точки для повторного измерения. Серый цвет обозначает отсутствие R².

Исходная калибровка

Показывает, как меняется измеренная проводимость при изменении концентрации кислоты.

Ошибка пересчёта концентрации, %

Показывает, на сколько процентов тренд завышает или занижает концентрацию стандарта. Логарифмическая ось помогает рассмотреть разбавленные точки.

Остатки по электропроводности

Показывает разницу между измеренной проводимостью с учётом фона и значением по тренду. По остаткам можно заметить выбросы и систематический изгиб.

Распределение ионных форм кислоты

Показывает, какие формы кислоты преобладают при разных pH. Нажми на метку pKₐ, чтобы увидеть доли всех форм при этом pH.

    Среднее число диссоциировавших протонов

    Показывает, сколько протонов в среднем отдаёт молекула кислоты при каждой концентрации. Расчёт без учёта автопротолиза воды.

    Расчётная концентрация от исходной

    Сравнивает концентрацию по тренду с заданной. Чем ближе точка к пунктирной линии y = x, тем точнее пересчёт.

    Сравнение калибровок всех кислот

    Позволяет сравнить наклон калибровочных прямых и диапазоны измерений разных кислот на общих осях.

      Пояснения и источники

      Обратная формула для расчёта C из [H⁺]

      C= h (h−Kwh) ⋅ DN = h (h−Kwh) ⋅ h3 +K1h2 +K1K2h +K1K2K3 K1h2 +2K1K2h +3K1K2K3

      Выбери обозначение, чтобы увидеть его смысл.

      h = [H⁺] — концентрация ионов водорода. C — концентрация кислоты, K₁, K₂ и K₃ — константы её ступеней диссоциации. Для отсутствующих ступеней соответствующие K равны нулю.

      Единица C совпадает с единицей h. Если h подставлено в мкмоль/л, для перевода C в моль/л раздели результат на 10⁶.

      Проводимость по Кольраушу для оси X

      κтеор= λH⁺h+ ∑i=1n λici +λOH⁻ Kwh 1000 −κчистая вода

      Две независимые поправки

      Автопротолиз добавляет [OH⁻] = Kᵥ/[H⁺] в баланс зарядов. При 25 °C Kᵥ = 10⁻¹⁴ (моль/л)². Закон Кольрауша суммирует λ°ᵢcᵢ для H⁺ и всех анионов кислоты. Вклад OH⁻ добавляется, если включён автопротолиз. Используются предельные молярные проводимости и приближение разбавленного раствора.
